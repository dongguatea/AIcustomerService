# MewHelp Ch03 向量知识库 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `query_faq` 的内核从 `Faq.question LIKE` 换成 BGE-M3 语义向量 + Milvus Top-K 检索，并搭好离线文档建库、对话挖知识、MySQL/Milvus 双写幂等一整条流水线，工具入参出参契约不变。

**Architecture:** 沿用 ch02 的 FastAPI 单进程同步 SQLAlchemy 栈；新增 `app/core/embeddings.py`（远程 BGE-M3）与 `app/core/retrieval.py`（dense 单路）、`app/kb/*`（切块/文档建模/去重/挖知识/Milvus 客户端/双写）。离线脚本 `scripts/*.py` 驱动「文档→切块→pending→embed→Milvus→done」，`query_faq` 只调 `retrieval.search_knowledge`。Milvus 用 Standalone（Docker etcd+minio+milvus，`http://localhost:19530`），MySQL 仍当原文权威源。

**Tech Stack:** Python 3.12, uv, FastAPI, SQLAlchemy 2.0 + PyMySQL, MySQL 8(Docker), Milvus Standalone(Docker), pymilvus, langchain-text-splitters, langchain `@tool` / `with_structured_output`, openai(AsyncOpenAI), pytest。

**Spec:** `docs/superpowers/specs/2026-10-28-ch03-vector-kb-design.md`

## Global Constraints

- 技术栈定死:BGE-M3（硅基流动 OpenAI 兼容，`BAAI/bge-m3`）、Milvus（Standalone）、MySQL 权威源；只跑 dense 单路，不碰 BM25/混合/重排。
- 工具契约不变:`query_faq(keyword: str) -> str`，命中拼「问/答」文本，未命中返回「未找到相关问题」。
- Milvus COSINE 口径按 Standalone:`distance` 即相似度（越大越相似），`score=float(distance)`；真实一致性由验收阶段 `kb-eval` 实证。
- 单测不打真实模型、不打真实 MySQL、不打真实嵌入、不打真实 Milvus；真实 MySQL 用 SQLite `StaticPool` 内存库代替，Milvus 客户端单测用 fake client。
- 异步测试在沙箱可能因本地 socket 创建而挂起，统一走 `require_escalated` 在沙箱外跑（沿 ch02 Task 4 结论）；同步测试不受影响。
- 每个任务完成即 commit；`dev-notes/ch03.md` 由主会话按阶段追记，不属于任何任务文件清单。
- 本机 Windows，`bash` 是 WSL stub；dev/test/eval 走 Makefile（纯 `uv run`）+ PowerShell/浏览器演示。

**Interfaces:**
- Consumes: `pymilvus.MilvusClient / DataType`，`app.config.settings.milvus_uri`。
- Produces:
  - 常量 `COLLECTION = "knowledge"`、`DIM = 1024`。
  - `async acall(fn, *args, **kwargs)`：单线程执行器（`ThreadPoolExecutor(max_workers=1)`）跑同步 pymilvus 调用。
  - `get_client(uri: str | None = None) -> MilvusClient`：传 uri 返回独立客户端，否则进程内单例（`MilvusClient(uri=settings.milvus_uri)`）。
  - `ensure_collection(client, collection=COLLECTION) -> None`：幂等，schema 含 `id:INT64(PK)`、`dense:FLOAT_VECTOR(dim=1024)`、`question/answer/section_path/content_type/category` 五个 VARCHAR 标量字段；`dense` 建 `AUTOINDEX` + `COSINE`。
  - `upsert_vectors(client, rows: list[dict], collection=COLLECTION) -> None`。
  - `dense_search(client, vector, top_k, category=None, collection=COLLECTION) -> list[dict]`：`search` 用 `anns_field="dense"`、`search_params={"metric_type":"COSINE"}`、`filter`（category 非空时 `category == "..."`）、`output_fields=["question","answer","section_path","content_type","category"]`；hit 归一化为 `{"id","score","question","answer","section_path","content_type","category"}`，`score = float(h["distance"])`（Standalone COSINE distance 即相似度，越大越相似）。
  - `count(client, collection=COLLECTION) -> int`、`drop(client, collection) -> None`。

from app.kb import milvus_client as mc


class FakeSchema:
    def __init__(self):
        self.fields = []

    def add_field(self, name, dtype, **kwargs):
        self.fields.append((name, getattr(dtype, "name", str(dtype)), kwargs))


class FakeIndexParams:
    def __init__(self):
        self.indexes = []

    def add_index(self, **kwargs):
        self.indexes.append(kwargs)


class FakeClient:
    def __init__(self):
        self._cols = {}
        self.upserts = []
        self.searches = []
        self.dropped = []

    def has_collection(self, name):
        return name in self._cols

    def load_collection(self, name):
        self._cols[name]["loaded"] = True

    def create_schema(self, auto_id=False):
        return FakeSchema()

    def prepare_index_params(self):
        return FakeIndexParams()

    def create_collection(self, name, schema=None, index_params=None):
        self._cols[name] = {"schema": schema, "index_params": index_params, "loaded": False}

    def upsert(self, name, rows):
        self.upserts.append((name, rows))

    def search(self, name, data, anns_field, limit, output_fields, search_params, filter):
        self.searches.append(dict(name=name, anns_field=anns_field, limit=limit,
                                  output_fields=output_fields, search_params=search_params,
                                  filter=filter))
        return [[{"id": 1, "distance": 0.87,
                  "entity": {"question": "q0", "answer": "a0", "section_path": "",
                             "content_type": "faq", "category": "商品"}}]]

    def query(self, name, filter, output_fields):
        return [{"count(*)": 7}]

    def drop_collection(self, name):
        self.dropped.append(name)
        self._cols.pop(name, None)


def test_ensure_collection_builds_dense_cosine_schema():
    client = FakeClient()
    mc.ensure_collection(client, "c")
    mc.ensure_collection(client, "c")  # 幂等
    schema = client._cols["c"]["schema"]
    assert [(n, d) for n, d, _ in schema.fields] == [
        ("id", "INT64"), ("dense", "FLOAT_VECTOR"), ("question", "VARCHAR"),
        ("answer", "VARCHAR"), ("section_path", "VARCHAR"),
        ("content_type", "VARCHAR"), ("category", "VARCHAR"),
    ]
    assert client._cols["c"]["index_params"].indexes == [
        {"field_name": "dense", "index_type": "AUTOINDEX", "metric_type": "COSINE"},
    ]
    assert client._cols["c"]["loaded"] is True


def test_upsert_and_dense_search_mapping():
    client = FakeClient()
    mc.ensure_collection(client, "c")
    row = {"id": 1, "dense": [0.0] * mc.DIM, "question": "q0", "answer": "a0",
           "section_path": "", "content_type": "faq", "category": "商品"}
    mc.upsert_vectors(client, [row], "c")
    hits = mc.dense_search(client, [0.0] * mc.DIM, top_k=5, category="商品", collection="c")
    assert hits == [{"id": 1, "score": 0.87, "question": "q0", "answer": "a0",

    s = client.searches[-1]
    assert s["anns_field"] == "dense" and s["limit"] == 5
    assert s["search_params"] == {"metric_type": "COSINE"}
    assert s["filter"] == 'category == "商品"'


def test_dense_search_no_category_uses_empty_filter():
