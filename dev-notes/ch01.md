- 翻车与返工(本次最重要):
  - DeepSeek 默认开启思考模式,`with_structured_output` 三条默认路径全部 400:
    `json_schema` response_format 不可用、`json_object` 要求 prompt 含 "json"、
    `function_calling` 的 `tool_choice` 在思考模式不可用。
  - 修复:新增 `chat_thinking=disabled` 配置,`llm.py` 经 `extra_body` 下发
    `thinking: disabled`;`extract.py` 显式 `method="function_calling"`。仍走
    `with_structured_output`,没有换方案。新增 2 条单测,全量 24 passed。
  - 附带发现:Windows PowerShell 的 `curl` 是 `Invoke-WebRequest` 别名,已写进 README。
  - 再返工:Windows PowerShell 5.1 即使改 `curl.exe`,`-d '{"...":"..."}'` 的双引号
    仍会被剥掉、中文按 GBK 编码,导致 `{"detail":"There was an error parsing the body"}`。
    最终新增 `scripts/demo_chat.ps1`(ConvertTo-Json + 无 BOM UTF-8 文件 + curl.exe
    --data-binary),README 同步改用它演示。
